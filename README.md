# tensorflow-aiexploration
Exploring AI with TensorFlow

The Python file reproduces the introductory MNIST input-pipeline example from the [TensorFlow Datasets README](https://github.com/tensorflow/datasets/blob/master/README.md) for Chapter 1 Programming Exercise 1-2.

Original project: TensorFlow Datasets, [Apache License 2.0](https://github.com/tensorflow/datasets/blob/master/LICENSE). The example is copied without changes. The first line is a commented notebook installation command; running this file assumes TensorFlow and TensorFlow Datasets are already installed.
